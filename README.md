# Cadastro de Usuário

Este projeto é uma aplicação simples de cadastro de usuários, onde o usuário pode inserir suas informações pessoais e visualizar um formulário de cadastro com os seguintes campos:

- Nome
- E-mail
- Estado Civil
- Sexo
- Idade

## Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilização da página, incluindo layout responsivo.
- **JavaScript**: Para adicionar interatividade, como a confirmação de envio do formulário.

## Funcionalidades

- Cadastro de Usuário com validação básica dos campos.
- Exibição de uma mensagem de confirmação de cadastro ao submeter o formulário.
- Layout responsivo para visualização em dispositivos móveis.
